# docs/

This folder contains **technical documentation** for Sky Auto Player.

It is **not** the website source. The website (GitHub Pages) lives in [`site/`](../site/)
and is built with Astro. The live site is at
<https://pumni.github.io/Sky-Auto-Player/>.

## Contents

| Path | Purpose |
|---|---|
| `architecture.md` | 4-layer DDD architecture overview |
| `rt-dispatch-architecture.md` | Real-time dispatch architecture |
| `timing-principles.md` | Timing principles and contracts |
| `timing-profile-frame-model.md` | Timing profile and frame model |
| `distribution-and-update.md` | Distribution, updater, and release pipeline |
| `INDEX.md` | Documentation map and hierarchy of truth |
| `archive/` | Historical plans and investigations (not normative) |
| `perf-baselines/` | Performance baseline measurements |
| `plan/` | Working proposals (not normative; normative docs win) |

## What was removed

The following website files were removed from `docs/` in PR #5 after the
Astro-based site was live and confirmed stable:

- `index.html`, `faq.html`, `vi/index.html`, `vi/faq.html`
- `assets/site.css`, `assets/site.js`, `assets/og-banner.jpg`, `assets/picker.webp`
- `.nojekyll`, `robots.txt`, `sitemap.xml`, `llms.txt`, `google40b614dcfbf81da7.html`

These are all now generated by `site/` and served via GitHub Actions Pages.
