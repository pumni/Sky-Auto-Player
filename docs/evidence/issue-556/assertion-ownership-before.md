## Known geometry ownership changes to make explicit after the split

- The Graphite header dimensions at baseline line 478 and Library row/tile dimensions at line 1201 are currently measured by Graphite-named tests. Wave B made those structural dimensions shared across all six palettes. Keep Graphite-specific color/semantic assertions; move the shared geometry contract to a shared-layout owner and compare against fixed expected values, never the production layout solver.
- Baseline line 1475's compact-navigation persistence is a layout/persistence assertion, not a Graphite color assertion. Give it the shared workbench owner. Keep `workbench-resize.spec.ts`'s independent all-palette pane geometry and v5 tests as the authority for Inspector widths/thresholds.
- Do not delete any assertion from the baseline. Transfer ownership or split a test only when every geometry, focus, color, event-order and accessibility assertion has a new named owner. No other old palette-specific geometry is marked invalid by this map.
