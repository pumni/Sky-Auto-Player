## Browser mock captures

These are Playwright browser captures, not native Tauri screenshots. The viewport sizes below are
CSS pixels. The populated and compact states use the mock library and dry-run playback; the narrow
state shows the Inspector as an overlay.

| Capture | Viewport | State |
| --- | ---: | --- |
| [1366×768 populated](browser-mock-1366x768-populated.png) | 1366×768 | Expanded navigator, selected track, dry-run playback, docked Details Inspector |
| [800×560 compact](browser-mock-800x560-compact.png) | 800×560 | Collapsed navigator, selected track, dry-run playback |
| [640×448 Inspector overlay](browser-mock-640x448-inspector-overlay.png) | 640×448 | Selected track, dry-run playback, Details Inspector overlay |

[Browser geometry measurements](browser-mock-geometry.json) include the captured workbench,
titlebar, pane, row, track header, classic-scrollbar simulation, and runtime diagnostics geometry.
They were generated by:

```powershell
$env:GRAPHITE_WORKSPACE_CAPTURE='candidate'
$env:GRAPHITE_WORKSPACE_CAPTURE_VIEWS='populated,compact,overlay'
bun run test:e2e -- tests/e2e/visual-evidence.spec.ts --grep "captures selected Graphite workspace evidence views on request"
```

Result: 1 test passed. This proves browser layout behavior only.

## Native Windows capture

[Native Win11 Snap Layout capture](native-win11-125-snap-layout-crop.png) is a crop from the live
Tauri app on Windows 11 Home, build 26300. The app was responsive, `GetDpiForWindow` returned 120
(125%), and the physical window rectangle was 1000×737 pixels (about 800×590 logical pixels). The
native Snap Layout flyout appeared when hovering the maximize hit target. The image is a 1040×345
physical-pixel crop of the 1920×1080 desktop, so it is explicitly native evidence rather than a
browser mock.

Smoke command: `bun run tauri:dev`. No game was launched and no gameplay input was sent.

The native logical titlebar scaling test passed with:

```powershell
cargo test --manifest-path rust/Cargo.toml -p sky_desktop_shell --lib --no-default-features --features tauri-test --locked snap_hit_target_tracks_the_shared_logical_titlebar_height_at_each_dpi
```

It checks 40 logical pixels at 96 DPI and 40, 50, 60, and 80 physical pixels at 96, 120, 144,
and 192 DPI respectively. The live host was available at 125% only. Manual native checks at 100%,
150%, and 200% remain pending; those display scales were not simulated.
