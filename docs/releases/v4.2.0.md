# Sky Auto Player v4.2.0

A refreshed desktop workbench with better library workflows, clearer playback feedback, and more reliable Windows playback.

- **New:** Graphite dark theme and a responsive Library, Search, Track Browser, and Inspector.
- **New:** Pre-playback Timing Advisory highlighting potential timing constraints without changing the music or playback behavior.
- **Improved:** Playlist creation, playlist-scoped imports, scoped search, keyboard navigation, and selection feedback.
- **Improved:** Persistent window and workspace layouts, adaptive Inspector, and clearer Auto Play, Shuffle, Dry Run, and playback status.
- **Fixed:** Playback edge cases involving Stop/Skip, focus, pause/resume, key-release recovery, and Windows sleep/hibernate.
