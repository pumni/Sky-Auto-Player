# Sky Auto Player v4.3.0

## New
- The built-in library gains six songs—*Experience*, *Fly Me To The Moon*, *Kiss The Rain*, *Passacaglia (Shinraki Sky)*, *Perfect*, and *The Scientist*—bringing the catalog from 106 to 112 entries.
- Choose System (Follow Windows), Light, or Dark appearance. Browse built-in songs in pages of up to 100, with navigation that keeps selection and playback context available as you move between pages.
- Supported versioned sheets show their schema and readiness for Sky's 15-key layout. If preparation would lose notes or tracks, review the proposed losses and accept them before playback is prepared.

## Improved
- Catalog browsing and search feel more responsive, and workbench pane resizing feels smoother.
- Startup restores saved window geometry before showing the main window, reducing the white flash and initial size jump.

## Fixed
- Settings changed around calibration are no longer replaced by a stale refresh.
- If the desktop UI stops rendering, an on-screen message advises closing and reopening the app.
