# Sky Auto Player v3.2.0rc1 — Superseded

> **Superseded candidate.** This tag is retained for history and will not be promoted. The replacement release uses unsigned portable distribution and manual updates.

## What is being validated

- In-app version checking and official manual-download hand-off.
- Unsigned portable packaging with SHA256, exact manifest, and provenance.
- No native automatic installation or application-file replacement.
- Defender, fresh-install, and dry-run qualification for the replacement release.
- Windows `RegisterHotKey` playback controls.
- Clean single-ZIP distribution with no legacy updater scripts.

## Upgrade note

Existing v3.1.0-or-older installations may require a one-time manual migration to this candidate. Extract into a new folder and copy `config.json`, `.env`, `songs/`, and `logs/` as needed.

Do not rely on the old BAT/PowerShell updater.
