# Sky Auto Player v3.2.0rc1

> **Release candidate — beta channel.** This build is for production-signing, Defender, package, and fresh-install qualification before v3.2.0 stable.

## What is being validated

- Native out-of-process **Update now** architecture.
- Production Authenticode signing and signer verification.
- SHA256 + exact manifest + archive safety checks.
- Transactional install and rollback.
- Windows `RegisterHotKey` playback controls.
- Clean single-ZIP distribution with no legacy updater scripts.

## Upgrade note

Existing v3.1.0-or-older installations may require a one-time manual migration to this candidate. Extract into a new folder and copy `config.json`, `.env`, `songs/`, and `logs/` as needed.

Do not rely on the old BAT/PowerShell updater.

## Candidate assets

- `Sky-Auto-Player-v3.2.0rc1.zip`
- `Sky-Auto-Player-v3.2.0rc1.zip.sha256`
- `MANIFEST.json`

Do not promote this candidate to stable until its acceptance record is complete.
