# Sky Auto Player v3.2.1rc1

Release candidate — beta channel. This is the first candidate for the
unsigned portable/manual-update model. v3.2.0 and its RC tags are retained
as aborted history and are not reused.

## Distribution

- `Sky-Auto-Player-v3.2.1rc1.zip`
- `Sky-Auto-Player-v3.2.1rc1.zip.sha256`
- `MANIFEST.json`

The package contains no native updater, BAT/PowerShell updater, or legacy
`Sky-Player.exe`. The release workflow hashes exact unsigned bytes and retains
SHA256 and GitHub build-provenance evidence.

## Updating

The app checks GitHub for a newer stable/beta version and opens the official
GitHub Releases page for manual download. It does not extract archives or
replace application files.

Windows binaries are currently distributed without an Authenticode publisher
certificate. Windows SmartScreen may display an unrecognized-app warning.
Download only from the official
<https://github.com/pumni/Sky-Auto-Player/releases> page and verify SHA256
when desired.

## Qualification

Do not promote this candidate until CI, frozen-app smoke, exact manifest,
canonical ZIP/SHA, provenance, fresh-install, dry-run playback, update
notification/manual-download, and Defender evidence are complete.
Authenticode: **N/A — intentionally unsigned**.
