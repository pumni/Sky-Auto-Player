# Sky Auto Player v4.5.0

## What's New & Improved

- **Refreshed interface:** New Sky Indigo styling, updated Graphite and Light themes, and redesigned titlebar icons.
- **Flexible workspace:** Collapsible Inspector, smoother panel resizing, and improved layout controls.
- **Easier playback settings:** Improved Playback Profile controls with timing hints and one-click application of available song recommendations.
- **Clearer feedback:** Redesigned Settings, Calibration, and Update dialogs with better status and progress information.
- **More reliable playback:** Improved playback preparation, key-release handling, and recovery from focus changes and interruptions.
- **Smoother interactions:** Improved search, keyboard navigation, and accessibility across the desktop interface.
