# Sky Auto Player v4.1.0

v4.1.0 focuses on playback reliability, faster desktop startup, and smoother day-to-day library workflows.

## Highlights

* Added Shuffle and Auto Play, with improved Previous/Next and natural-finish handoff behavior.
* Reworked normal playback around prepared absolute-frame dispatch for a leaner, more predictable `SendInput` path.
* Improved focus, pause/resume, suspend, cleanup, and successor-playback reliability.
* Improved startup with persistent catalog caching, background reconciliation, and lazy-loaded desktop surfaces.
* Added clearer playback diagnostics and a configurable Timing Margin for prepared playback sessions.
* Added Windows single-instance behavior and strengthened Tauri authorization, dependency scanning, and release verification.
