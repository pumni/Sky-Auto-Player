# Sky Auto Player v4.1.0

v4.1.0 improves playback timing, session reliability, and day-to-day library workflows.

## Highlights

- More responsive and consistent normal playback through a prepared dispatch path, with improved handling for holds, pauses, focus changes, and natural completion.
- New playback timing controls, including a configurable timing margin and bounded normal Down continuity tolerance. Changes apply to the next prepared session.
- Clearer playback readiness, confirmation, status recovery, and diagnostics so playback issues are easier to understand and recover from.
- Expanded runtime telemetry for inspecting timing and input health during playback.
- Smoother library navigation with All Songs search/browse support and more reliable catalog loading and caching.
