# Sky Auto Player v3.2.1

Sky Auto Player v3.2.1 is the unsigned portable/manual-update release.
v3.2.0 and its RC tags remain immutable aborted history and are not reused.

## Distribution

- `Sky-Auto-Player-v3.2.1.zip`
- `Sky-Auto-Player-v3.2.1.zip.sha256`
- `MANIFEST.json`

The package contains no native updater, BAT/PowerShell updater, or legacy
`Sky-Player.exe`. The release workflow hashes exact unsigned bytes and retains
SHA256 and GitHub build-provenance evidence.

## Updating

The app checks GitHub for a newer stable/beta version and opens the official
GitHub Releases page for manual download. It does not extract archives or
replace application files.

Windows binaries in this release are currently distributed without an
Authenticode publisher certificate. Windows SmartScreen may display an
unrecognized-app warning. Download only from the official
<https://github.com/pumni/Sky-Auto-Player/releases> page and verify SHA256
when desired.

## Compatibility

Extract the release into a new folder and copy `config.json`, `.env`,
`songs/`, and `logs/` as needed. Stable ignores prereleases; beta may
receive release candidates.

Authenticode: **N/A — intentionally unsigned**.
