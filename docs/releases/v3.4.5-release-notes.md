# Sky Auto Player v3.4.5

v3.4.5 is the fixed updater bridge release. Users on an older updater must
manually install this release from the official GitHub Releases page before
trusting native self-update again.

## Highlights

- Adds a visible native updater progress window with explicit lifecycle phases.
- Adds a bounded ready/rejected handoff so Python does not exit before the
  native updater is ready to own the update.
- Adds per-install active-update state and a frozen-startup guard for duplicate
  launches.
- Adds bounded result provenance and non-fatal post-commit cleanup warnings.
- Keeps update downloads, verification, replacement, rollback, and restart in
  the native updater; Python does not mutate application files.

## Security

The public package remains portable and intentionally unsigned. The updater
continues to use the fixed GitHub HTTPS allow-list, exact SHA256/archive/
manifest verification, preserved user paths, transactional replacement, and
rollback. It does not modify game files, read game memory, bypass anti-cheat,
inject code, install hooks, or send keyboard/mouse input.
