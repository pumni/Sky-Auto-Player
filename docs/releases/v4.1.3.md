# Sky Auto Player v4.1.3

v4.1.3 is the corrective control-plane release after the v4.1.2 post-publication incident.

- v4.1.2 binaries were published immutably, but stable updater metadata did not advance because
  the `PromoteMetadata` workflow invocation omitted the required `-ReleaseNotesPath` parameter.
- v4.1.3 fixes the production YAML-to-PowerShell invocation contract for all five release states,
  including the latent `FinalVerify` omission.
- Static acceptance checks now validate every required state-specific CLI argument and reject
  missing `PromoteMetadata`/`FinalVerify` release-notes or shared identity arguments.

This release contains no unrelated application or runtime feature claims.
