# Sky Auto Player v3.2.0 — Aborted / not published

This tag is retained as an immutable release record only. The v3.2.0
production release was aborted after its signing-gated workflow failed before
building or publishing release assets. Do not publish or recreate this tag.
The unsigned/manual-update model is released under a new version, beginning
with v3.2.1rc1.

## Highlights

- **Manual updates.** The app checks for new versions and opens the official GitHub Releases page; it never performs automatic installation.
- **Unsigned portable distribution.** Public Windows binaries have no Authenticode publisher certificate. SHA256, the exact manifest, and GitHub build provenance remain available as integrity/provenance evidence.
- **Lower-noise global controls.** Playback controls use Windows `RegisterHotKey` / `WM_HOTKEY` instead of continuous key-state polling.
- **Less aggressive focus handling.** Startup no longer forces the Sky window to the foreground; refocus is an explicit user action.
- **Hardened release pipeline.** The manifest hashes exact unsigned packaged bytes, and release assets carry SHA256 and build-provenance evidence.

## Important upgrade note

**If you are upgrading from v3.1.0 or an older release, plan for one manual migration.**

The legacy BAT/PowerShell updater and old `Sky-Player.exe` compatibility path are intentionally not included in v3.2.0.

Recommended one-time migration:

1. Close the old Sky Auto Player.
2. Download and extract `Sky-Auto-Player-v3.2.0.zip` into a **new folder**.
3. Copy your user data from the old install as needed:
   - `config.json`
   - `.env`
   - `songs/`
   - `logs/`
4. Start `Sky-Auto-Player.exe` from the new folder.

For the replacement release, **Open GitHub Releases** is the supported update action. Extract it into a new folder and copy user-owned state as needed.

## Security and reliability

The public app does not extract archives or replace application files. The
source-only Rust updater remains separately tested and fail-closed, including
its publisher-verification boundary; it is not shipped in the public package.
The playback dispatcher remains isolated and the project does not read game
memory, inject code, install hooks, or modify game files.

## Distribution

v3.2.0 has no public release assets. The replacement release ships one canonical set:

- `Sky-Auto-Player-v3.2.0.zip` (not published)
- `Sky-Auto-Player-v3.2.0.zip.sha256` (not published)
- `MANIFEST.json`

Authenticode: **N/A — intentionally unsigned** for the replacement release.
Windows SmartScreen may show an unrecognized-app warning. Download only from
the official GitHub Releases page and verify SHA256 when desired.

There is no legacy bridge ZIP, BAT updater, PowerShell updater, or alternate executable-name package.

## Compatibility

- Windows 10/11 x64.
- Packaged builds include their own Python runtime.
- `config.json`, `.env`, `songs/`, and `logs/` are preserved by manual migration.
- Stable channel ignores prereleases; beta channel may receive release candidates.
