# Sky Auto Player v3.2.0

Sky Auto Player 3.2.0 introduces a native, transactional self-update flow for Windows, hardens release verification, and replaces continuous playback-hotkey polling with OS-registered global hotkeys.

## Highlights

- **Native “Update now” flow.** The app now hands updates to a dedicated Rust updater that runs outside the install directory, verifies the release, applies it transactionally, and restarts the verified app.
- **Safer updates.** Release ZIPs are checked with SHA256, archive-path validation, an exact manifest, and Authenticode verification before managed files are changed.
- **Rollback and recovery.** Updates use a durable journal and verified backups so a failed install can roll back without touching user-owned data.
- **Lower-noise global controls.** Playback controls use Windows `RegisterHotKey` / `WM_HOTKEY` instead of continuous key-state polling.
- **Less aggressive focus handling.** Startup no longer forces the Sky window to the foreground; refocus is an explicit user action.
- **Hardened release pipeline.** Project-owned Windows binaries are signed before `MANIFEST.json` is generated, and release assets carry SHA256 and build-provenance evidence.

## Important upgrade note

**If you are upgrading from v3.1.0 or an older release, plan for one manual migration.**

The legacy BAT/PowerShell updater and old `Sky-Player.exe` compatibility path are intentionally not included in v3.2.0.

Recommended one-time migration:

1. Close the old Sky Auto Player.
2. Download and extract `Sky-Auto-Player-v3.2.0.zip` into a **new folder**.
3. Copy your user data from the old install as needed:
   - `config.json`
   - `.env`
   - `songs/`
   - `logs/`
4. Start `Sky-Auto-Player.exe` from the new folder.

From v3.2.0 onward, **Update now** is the supported update path.

## Security and reliability

The native updater:

- fetches an exact GitHub release tag and exact canonical assets;
- accepts HTTPS only and validates every redirect against the project host allow-list;
- verifies the ZIP SHA256 before extraction;
- rejects unsafe Windows archive paths, traversal, symlinks/reparse escapes, duplicate/case-colliding entries, and file/directory collisions;
- verifies the exact release manifest and the actual Authenticode signer;
- preserves `config.json`, `.env`, `songs/`, and `logs/`;
- never deletes arbitrary unmanifested user files;
- verifies rollback material before destructive recovery;
- writes the update result before restarting a verified application binary.

The updater remains isolated from the playback dispatcher and does not read game memory, inject code, install hooks, or modify game files.

## Distribution

v3.2.0 ships one canonical release set:

- `Sky-Auto-Player-v3.2.0.zip`
- `Sky-Auto-Player-v3.2.0.zip.sha256`
- `MANIFEST.json`

There is no legacy bridge ZIP, BAT updater, PowerShell updater, or alternate executable-name package.

## Compatibility

- Windows 10/11 x64.
- Packaged builds include their own Python runtime.
- `config.json`, `.env`, `songs/`, and `logs/` are preserved by native self-update.
- Stable channel ignores prereleases; beta channel may receive release candidates.
