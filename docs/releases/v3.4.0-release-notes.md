# Sky Auto Player v3.4.0

v3.4.0 tightens native playback timing and recovery.

## Highlights

- Deterministic authored timing with stricter hold-feasibility validation.
- Per-key release scheduling and recovery for missed or hard-late input.
- More reliable focus-loss/resume and foreground activation handling.
- Stronger calibration provenance, telemetry, and dispatch validation.
- Fixed missed-note counters in the playback progress UI.

## Platform

Windows 10/11 x64.
