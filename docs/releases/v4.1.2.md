# Sky Auto Player v4.1.2

v4.1.2 is a corrective release after the v4.1.1 post-publication control-plane failure.

v4.1.1 binaries were published immutably, but stable updater metadata remained at `4.0.1`.
This release removes stale cross-step publication state, hardens pre-publication metadata and
GitHub App validation, and adds exact final verification of the remote release and metadata bytes.

This release contains no unrelated application or runtime feature claims.

## Historical publication incident

Production run #29 (`35437172205`) published the v4.1.2 binaries and tag immutably and made the
release GitHub Latest, but stable updater metadata did not advance. The `PromoteMetadata` workflow
invocation omitted the required `-ReleaseNotesPath` argument and failed closed after publication;
`FinalVerify` contained the same latent invocation defect. v4.1.2 remains an immutable incident
record, not a successful metadata promotion. The corrective SemVer target is [v4.1.3](v4.1.3.md).
