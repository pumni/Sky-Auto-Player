# Sky Auto Player v3.3.0

v3.3.0 focuses on a cleaner native update path and a simpler,
more robust real-time playback architecture.

## Highlights

- Added the native Rust Update and Restart flow.
- Removed legacy BAT/PowerShell updater artifacts from the public package.
- Improved transactional update verification, rollback, and recovery.
- Preserved user data during updates: `config.json`, `.env`, `songs/**`, and
  `logs/**`.
- Improved focus-loss handling and playback recovery.
- Simplified the real-time dispatch path and removed legacy adaptive state.
- Hardened packaged release integrity and provenance verification.

## Updating from v3.1.0

v3.1.0 users should migrate to v3.3.0 using the official GitHub release ZIP.

After v3.3.0 is installed, future supported updates can use the native
Update and Restart flow.

## Platform

Windows 10/11 x64.
