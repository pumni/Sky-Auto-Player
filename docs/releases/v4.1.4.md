# Sky Auto Player v4.1.4

Sky Auto Player v4.1.4 improves playback reliability, accessibility, search and settings
interactions, and update progress feedback.

- **Playback and input reliability:** Key press/release behavior is more consistent when
  scheduling is delayed, late input is handled more safely, and final foreground/focus checks
  happen close to dispatch. The player also behaves more safely when Windows process-integrity
  constraints prevent a valid target from being selected.
- **Appearance and accessibility:** Semantic colors and control states are more consistent, with
  improved behavior for Windows forced-colors and accessibility settings.
- **Search and settings:** Search focus and draft behavior are more stable, slash shortcuts stay
  local around editable controls, and settings persistence failures provide clearer recovery and
  feedback.
- **Updater experience:** Cumulative download progress now reports progress more accurately.
