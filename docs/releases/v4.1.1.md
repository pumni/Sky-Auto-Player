# Sky Auto Player v4.1.1

v4.1.1 is a corrective release that completes the v4.1 rollout after the v4.1.0 binaries were published and made immutable, but stable updater metadata did not advance because the release workflow failed after publication.

## Highlights

* Includes the playback reliability, Shuffle, Auto Play, startup, diagnostics, and desktop workflow improvements introduced in v4.1.0.
* Hardens release publication reconciliation so external GitHub state is re-read after the irreversible publication boundary.
* Adds strict release-state schema validation and fail-closed handling for ambiguous remote publication state.
* Adds a read-only release doctor for diagnosing pre-publication and post-publication release states.
* Strengthens workflow identity, repository identity, timestamp, and immutable-release verification.
