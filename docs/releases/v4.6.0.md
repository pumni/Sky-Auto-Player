# Sky Auto Player v4.6.0

## What's New & Improved

- **Reworked playback engine:** More direct note scheduling, consistent key holds and removal of unnecessary release gaps, with improved handling of rapid repeated notes and pause/resume.
- **Expanded song library:** 41 new curated piano arrangements, bringing the built-in collection to 153 songs across pop, anime, film and instrumental music.
- **Graphite 2.0:** A cleaner Dark and Light desktop interface, with a unified workbench, refined player controls and redesigned Settings.
- **Smoother interactions:** Refined global search with one clear button, improved keyboard navigation, compact layouts, focus indicators and reduced-motion support.
- **Clearer playback guidance:** Improved note-registration warnings, timing feedback and runtime diagnostics.
- **Easier updates:** Fresh update checks on every launch when automatic checking is enabled, with clearer update status and progress.
