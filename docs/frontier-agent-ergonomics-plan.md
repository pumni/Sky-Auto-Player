## Outcome and definition of done

Improve the entire developer feedback loop for current and future frontier reasoning models: independent environment, accurate and timely verification, production-path evidence, legible and cohesive code, minimal current context, reproducible debugging, safe authority and empirically measured agent effectiveness. Deliver one integrated, maintainable system, not a pile of tools. No model-specific orchestration runtime, mandatory subagents, mechanical plan rituals, universal TDD, arbitrary LOC thresholds, duplicate instruction files or speculative dependencies. Existing product behavior, public wire identities, security/release authority, native timing/focus/cleanup and required CI remain intact. This plan explicitly includes all audit opportunities; each must be delivered or receive a documented Leader rejection based on evidence, not silently deferred.

End state: canonical code and docs describe one current architecture; all replaced paths and obsolete private names, compatibility aliases without real consumers, tests for removed paths, temporary notes and stale instructions are removed in the same PR. Preserve public identifiers, live external consumers, historical evidence and security checks. Historical material stays accessible by immutable commit; do not delete valid fixtures, user data or original historical records. No manufactured evidence, assertion weakening, silently regenerated oracles, skipped gates or unsupported efficiency claims.

## Evidence and measurement conventions

Record environment (OS/architecture, pinned Rust/Bun, browser versions, relevant capabilities, warm/cold state), exact commit and source tree, commands, exit codes and actual coverage. Capture baseline where possible from the immutable production SHA using a disposable detached worktree with isolated outputs; do not rerun costly historic native measurements on unchanged behavior. Compare like with like; clearly separate baseline, candidate, simulation, mock browser, packaged and native evidence. Use monotonic elapsed time for command durations; report median only with enough comparable repeats, distributions when available; no guessed performance gains or p95 from tiny samples. No absolute latency targets without baseline. Existing scripts/ci_metrics.mjs is the CI metrics owner. Missing evidence = NOT RUN/BLOCKED, not PASS. No machine-local production credentials in agent shell, no network escalation without authorization.
