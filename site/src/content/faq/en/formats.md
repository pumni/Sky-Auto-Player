question: "What file formats does Sky Auto Player support?"
---

The supported set is JSON, `.skysheet` and JSON-compatible TXT. These files contain the structured sheet data that Sky Auto Player reads. See the [source extension list](https://github.com/pumni/Sky-Auto-Player/blob/main/src/sky_music/ui/picker_helpers.py) for the current implementation.
