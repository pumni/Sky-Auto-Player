question: 'What file formats does Sky Auto Player support?'
---

The supported set is JSON, `.skysheet` and JSON-compatible TXT. These files contain the structured sheet data that Sky Auto Player reads. See the [native song parser](https://github.com/pumni/Sky-Auto-Player/blob/main/rust/crates/sky_app_core/src/song.rs) for the current implementation.
