question: "Can I build Sky Auto Player from source?"
---

Yes. Clone the [repository](https://github.com/pumni/Sky-Auto-Player), run `uv sync`, then launch with `uv run python src/main.py`. The repository documents the Python 3.14 free-threaded environment and doctor checks.
