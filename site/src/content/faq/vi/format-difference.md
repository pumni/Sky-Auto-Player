question: "S\u1ef1 kh\u00e1c nhau gi\u1eefa JSON, skysheet v\u00e0 TXT l\u00e0 g\u00ec?"
---

JSON là dạng có cấu trúc chuẩn. File `.skysheet` là sheet dựa trên JSON với phần mở rộng đó, còn TXT là file văn bản thuần chứa cấu trúc tương thích JSON.
