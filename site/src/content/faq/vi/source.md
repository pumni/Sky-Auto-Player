Có. Clone [repository](https://github.com/pumni/Sky-Auto-Player), cài Rust toolchain được ghim
và Bun, sau đó build workspace Tauri native trong `desktop/`. Các script release tạm thời của
repository có thể dùng Python tooling trong Wave 5, nhưng ứng dụng được hỗ trợ và GUI đóng gói
không cần Python.
