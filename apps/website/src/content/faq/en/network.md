question: 'Why are some notes dropped during playback?'
---

If other players hear missing notes, first compare local playback and network conditions. Packet loss or latency can affect what reaches the game server. A different network route may help in some cases; some users try [Cloudflare WARP](https://1.1.1.1/), but no third-party network tool is guaranteed to solve the problem.
